# Wine Quality Exploratory Data Analysis

## Project Overview

This project focuses on exploring and analyzing the Wine Quality Dataset to understand the factors affecting wine quality. Various statistical techniques, correlation analysis, and visualizations were used to identify important patterns and relationships within the data.

## Objective

To explore the factors affecting wine quality and identify relationships between physicochemical properties and quality scores.

## Dataset

- Dataset: Wine Quality Dataset
- Source: Kaggle / UCI Machine Learning Repository
- Format: CSV

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Data Cleaning

- Loaded the dataset using Pandas.
- Checked for missing values.
- Removed duplicate records.
- Verified data types.
- Identified and treated outliers using the IQR method.

## Statistical Analysis

- Calculated mean, median, mode, variance, and standard deviation.
- Analyzed feature distributions.
- Examined wine quality score distributions.

## Correlation Analysis

- Generated a correlation matrix.
- Created a correlation heatmap.
- Identified highly correlated features.
- Studied relationships between wine properties and quality scores.

## Visualizations Created

- Histogram
- Correlation Heatmap
- Boxplots
- Scatter Plot
- Bar Chart

## Key Observations

1. Alcohol content showed a positive relationship with wine quality.
2. Volatile acidity showed a negative relationship with wine quality.
3. Most wines belonged to the medium-quality category.
4. Outliers were present in several numerical features.
5. Strong correlations existed among certain chemical properties.

## Conclusion

The analysis showed that wine quality is influenced by multiple physicochemical characteristics. Alcohol content and acidity levels were among the most significant factors affecting quality. The project demonstrates the effectiveness of exploratory data analysis in discovering meaningful insights from datasets.
